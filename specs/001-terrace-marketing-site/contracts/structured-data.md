# Contract: Structured data and meta tags

Every value is imported from `src/config/business.ts`, with computed values from
`src/config/derived.ts` (see [business-config.md](./business-config.md)). `JsonLd.astro` builds the
object and serializes it with `JSON.stringify`. Nothing is hard-coded in components. Placeholders
below use the config field names.

**`{site}`** is the one resolved site URL: `new URL(import.meta.env.BASE_URL, Astro.site)` without
the trailing slash. Astro's `site` comes from `business.websiteUrl`, and CI's `SITE_URL` may
override it. The canonical tag, `og:url`, `og:image`, the JSON-LD URLs, the sitemap, and
`robots.txt` all use `{site}`, so they always agree. (The JSON-LD `url` therefore matches the
canonical tag even before a custom domain is set up.) No component reads `business.websiteUrl`
directly.

## JSON-LD (`<script type="application/ld+json">` in `<head>`)

```json
{
  "@context": "https://schema.org",
  "@type": "GeneralContractor",
  "@id": "{site}/#business",
  "name": "{business.name}",
  "alternateName": "{business.short_name}",
  "url": "{site}/",
  "telephone": "{phone_e164}",
  "foundingDate": "{founded_year}",
  "logo": "{site}/logo/brown-co-icon.svg",
  "image": "{site}/og-image.png",
  "description": "{seo.description}",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "{contact.street}",
    "addressLocality": "{contact.city}",
    "addressRegion": "{contact.state}",
    "postalCode": "{contact.zip}",
    "addressCountry": "US"
  },
  "geo": { "@type": "GeoCoordinates", "latitude": 40.99, "longitude": -95.45 },
  "areaServed": [
    {
      "@type": "GeoCircle",
      "geoMidpoint": { "@type": "GeoCoordinates", "latitude": 40.99, "longitude": -95.45 },
      "geoRadius": "160934"
    },
    { "@type": "AdministrativeArea", "name": "Mills County, Iowa" }
    /* …one entry per county… */
  ],
  "hasOfferCatalog": {
    "@type": "OfferCatalog",
    "name": "Services",
    "itemListElement": [
      { "@type": "Offer", "itemOffered": { "@type": "Service", "name": "Terrace construction and repair" } }
      /* …one per terraces.offerings[] and services[] name… */
    ]
  }
}
```

Rules:
- `geoRadius` = `radius_miles × 1609.34`, rounded, in meters.
- Counties render as `"{name} County, {state_name}"`.
- `telephone` MUST equal the E.164 number used in every `tel:` href. This is checked post-build.
- The JSON-LD MUST parse, and it MUST validate without errors in the Schema.org validator
  (manual gate in quickstart).
- It contains no V-BAN language.

## Meta and Open Graph

| Tag | Value |
|-----|-------|
| `<title>` | `seo.title` |
| `meta[name=description]` | `seo.description` |
| `link[rel=canonical]` | `{site}/` |
| `meta[name=theme-color]` | `#3B2A1A` |
| `og:type` | `website` |
| `og:site_name` | `business.name` |
| `og:title` | `seo.title` |
| `og:description` | `seo.description` |
| `og:url` | `{site}/` |
| `og:image` | `{site}/og-image.png` (1200×630), plus `og:image:width`/`height`/`alt` |
| `og:locale` | `en_US` |
| `twitter:card` | `summary_large_image` |

## Icons and manifest (generated by `scripts/prebuild.mjs` from `public/logo/brown-co-icon.svg`)

`/favicon.ico` (32), `/favicon.svg`, `/apple-touch-icon.png` (180), `/icon-192.png`,
`/icon-512.png`, `/site.webmanifest` (`name`, `short_name`, `theme_color` #3B2A1A,
`background_color` #F5F0E6, icons), `/og-image.png`.

## Crawl files

- `/robots.txt`: generated by the static endpoint `src/pages/robots.txt.ts` from Astro's `site`
  (which comes from `websiteUrl`). It allows everything and points to the sitemap. It is not written
  by hand.
- Sitemap: generated by `@astrojs/sitemap` (single URL). All URLs respect `SITE_URL`/`BASE_PATH`
  so they are correct under a GitHub Pages project subpath.
